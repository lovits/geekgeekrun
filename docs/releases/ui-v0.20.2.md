# GeekGeekRun Pro 0.20.2

本次更新加入可跨设备迁移的配置管理，并完善本机 Pi 模型接入和模型输入预览。安装包不包含个人简历、求职偏好、账号密钥或登录信息；升级继续使用设备上的现有数据。

## 新增与改进

- 左下角“设置”中新增导出配置、导入配置，保留自动更新设置；导入前自动备份已有配置。
- 配置文件包含求职条件、公司名单、简历文字、AI 匹配及模型设置；不导出登录状态、模型密钥、本机程序路径和本地简历 PDF 引用。换设备后需自行登录并重新选择简历 PDF。
- 支持通过本机 Pi CLI 调用已配置的模型，可自动识别或手动指定程序路径；需要用户自行安装、配置并登录 Pi。
- 调整 AI 匹配输入预览、评分说明和求职偏好模板；BOSS 活跃度不再作为可选模型输入，仍按原有岗位筛选设置执行。

## 安装包

- `geekgeekrun-pro_0.20.2_arm64.dmg`：Apple 芯片 Mac。
- `geekgeekrun-pro_0.20.2_x64.dmg`：Intel Mac。
- `geekgeekrun-pro_0.20.2_x64_setup.exe`：Windows 10／11 x64。
- `geekgeekrun-pro_0.20.2_amd64.deb`：Debian／Ubuntu x64。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。

Mac 安装包采用临时签名、未经过 Apple 公证；Windows 安装包未使用商业代码签名。构建和自动化检查不等同于所有设备上的完整界面或 BOSS 在线测试。
