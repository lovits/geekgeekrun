## GeekGeekRun Pro 0.20.0

基于 GeekGeekRun 的增强版本，保留原项目作者及许可证。

- 公共正则与 AI 筛选可组合使用，支持本地 Codex CLI 与 API 接入、简历解析、反馈学习和完整设置预览。
- 模拟开聊支持本地职位库与 BOSS 在线两种模式，在线模拟不点击沟通、不发送消息。
- 公司库支持期望／屏蔽公司切换及职位预览；职位库支持公司筛选与排序。
- 统一运行数据列表，增加模拟分页、记录导出，恢复 BOSS 活跃度滑动条。
- 修复配置并发写入，分别打包各平台 Electron 对应的 SQLite 原生组件。

### 安装包

- `arm64.dmg`：Apple 芯片 Mac。
- `x64.dmg`：Intel Mac。
- `x64_setup.exe`：Windows 10／11 x64 安装程序。
- `amd64.deb`：Linux x64。
- `SHA256SUMS.txt`：安装包校验值。

本版本未使用 Apple Developer 公证或 Windows 商业代码签名证书，系统可能提示验证发布者。已有用户配置与运行记录保留在原有本地数据目录；不会包含在安装包中。
