# Geek Geek Run-Pro 0.20.3

本次版本在 0.20.2 的基础上调整应用名称和更新提示，继续支持配置导入导出、Pi/Codex 和 API 模型接入、岗位匹配与模拟开聊。

## 更新内容

- 应用名称调整为 Geek Geek Run-Pro，保留原有本机数据目录。
- 更新提醒集中显示在“设置”页面，左下角不再显示更新提示；设置中仍可检查更新、查看发布说明和下载安装包。
- 启动时将缓存的更新版本与当前版本比较，已安装相同或更高版本后，不再显示过期的新版本提醒。

## 安装包

- `geekgeekrun-pro_0.20.3_arm64.dmg`：Apple 芯片 Mac。
- `geekgeekrun-pro_0.20.3_x64.dmg`：Intel Mac。
- `geekgeekrun-pro_0.20.3_x64_setup.exe`：Windows 10／11 x64。
- `geekgeekrun-pro_0.20.3_amd64.deb`：Debian／Ubuntu x64。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。

Mac 安装包采用临时签名、未经过 Apple 公证；Windows 安装包未使用商业代码签名。构建和自动化检查不等同于所有设备上的完整界面或 BOSS 在线测试。
