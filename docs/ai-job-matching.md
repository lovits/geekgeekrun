# 可组合的正则与 AI 岗位匹配

## 配置入口

- **公共职位正则筛选**：分别启用名称、类型、描述、期望公司名单和屏蔽公司正则。
- **AI 模型筛选**：分别启用名称和描述判断，导入简历、编辑求职偏好与提示词，并测试单条岗位。
- **配置大语言模型**：选择 OpenAI 兼容 API 或本机 Codex CLI。Codex 使用已有登录，无需把登录令牌复制到本项目。

同一字段勾选多项检查时，全部通过才放行。未启用的正则不会作为程序硬筛，但在用户勾选“正则条件输入”时可作为 AI 理解偏好的背景；未勾选的输入不会发送。职位列表和 BOSS 原生筛选保持独立。

## 模型与简历

本机需要安装 Codex CLI 并执行 `codex login`。模型与推理强度从本机 `app-server` 的 `model/list` 获取，目录可能来自缓存，不代表账号必然能调用每个模型；用“测试连接”确认。推理强度跟随模型的能力列表。CLI 在本机启动，模型推理仍通过配置的云端服务完成。上下文长度可在模型设置页调整；默认值及上限读取本机模型缓存，最小可设 4096 tokens。恢复默认不传覆盖值，自定义值通过 Codex 的 model_context_window 传入；不能借此突破模型上限，实际可用性仍需连接测试。

PDF 导入使用 Poppler（macOS 可执行 `brew install poppler`），最多 6 页、10 MB；页面图片与原始文字一起送到所选模型恢复阅读顺序。TXT/Markdown 可用 AI 整理文字。保留原始文本和不确定项，整理结果可编辑后保存；不会向招聘者发送简历。图片模型不支持、解析失败或格式无效时不替换原简历。当前 macOS PDF 工具路径适配 Homebrew Apple Silicon 安装；其他安装路径需调整。

## 匹配结果与反馈

AI 返回 0–100 基础分、匹配结论、综合条件、理由及差异。分数不是录取概率，不能代替资格判断。列表只显示摘要，完整理由和职责放在“详情”中。

在“开聊记录”中点击喜欢或不喜欢，再次点击取消；同一岗位的不同开聊记录共用标记。反馈持久化在本机，不训练远端模型，不修改 BOSS 推荐算法。勾选“喜欢/不喜欢反馈”作为输入后，按职责与技术相似度选取少量正负例，供后续 AI 参考；评分另外显示最多 ±10 分的相似偏好调整，不能把不匹配改为匹配，也不能覆盖硬性条件。不会因一个岗位不喜欢就屏蔽整家公司。没有配置或启用大模型时按钮置灰，后端也拒绝写入。只有 AI 筛选及反馈输入启用且存在模型配置时，明确不喜欢的同一岗位会直接跳过；关闭反馈输入后，不使用历史标记与自动总结。未标记不影响评分。

每次新增、修改或取消标记后，当前模型从最近最多100条明确反馈整理全局求职偏好的反馈学习部分，手写偏好保留。下次匹配同时使用手写偏好、自动总结与相关正负例；取消所有标记则清空自动总结。总结失败保留标记、清空旧自动总结并提示，不伪造结果。不会训练模型或改写用户手写的硬性条件。反馈更新串行处理。

默认主动输入仅勾选简历、求职偏好、求职类型/遍历方式、喜欢/不喜欢；正则、公司名单和其他页面条件默认不发送，仍可手动启用。

运行数据侧栏的“导出记录”可按类型与条件导出；开聊、不合适、职位、公司页面也各有入口，BOSS库不新增入口。单类支持CSV/JSON，可按公司、岗位、工作地、北京时间日期范围和喜欢/不喜欢筛选；不合适记录支持原因筛选，公司库支持行业关键词。日期范围取该类型的开聊时间、标记时间或岗位发布日期，日期缺失者在设置日期范围后不纳入。CSV保留全部字段、转义多行与引号、防止公式执行，不限当前分页。选择全部历史记录时沿用原完整JSON：数据库中的开聊、不合适标记、职位/公司/BOSS库、历史变化和运行记录，以及反馈、匹配审计、评分示例与自动总结。导出完整数据而非当前分页；不包含 API 密钥或登录凭据。

模型错误、格式无效、岗位在审核期间发生变化时不发送。可选 `GEEKGEEKRUN_CHAT_REVIEW_DIR` 保留逐条人工/外部审核协议；没有审批会等待并超时拒绝，不自动放行。

## 本地数据与验证

简历、账号、API 配置、反馈、审核记录均保存在用户目录 `~/.geekgeekrun/`，不提交到仓库。模型会收到用户勾选的资料及待评岗位，需自行确认服务商与账号。

```sh
node --test packages/utils/*test.mjs packages/geek-auto-start-chat-with-boss/*.test.mjs
pnpm --dir packages/ui build
```

修改包含 BOSS 实习/全国筛选及开聊前职位一致性校验。真实 BOSS 页面访问与模型权限可能变化；测试模型连接或岗位匹配不会发送招聘消息。项目整体类型检查存在既有错误，不能将构建成功等同于全量类型检查通过。

完整筛选设置使用只读表单展示，并提供原设置页入口；反馈总结仍位于“求职偏好→反馈学习的偏好”，刷新时同步总结及更新时间，不覆盖尚未保存的手写内容。自动开聊的自由组合栏按城市、求职类型、薪资、经验、学历、行业、规模横向排列，原工作地/薪资/经验补充校验放在同区折叠项内，字段、取值及逻辑保持原样。
