# GeekGeekRun Pro 0.20.1

本次更新保留现有匹配提示词和固定审核规则，完善规则复筛、记录与配置预览。新安装不附带个人简历、求职偏好、公司选择、模型账号或登录信息；升级继续使用用户自己的本地数据。

## 新增与改进

- 公共职位正则筛选新增独立的工作经验正则，与名称、分类、描述规则分别配置。
- 正则支持填写中文说明，完整设置预览以说明为主、原始表达式折叠展示；修改规则后可同步维护说明。
- 仅本地标记不合适时，原因先持久化到待处理队列，再在后台写入数据库，筛选继续处理下一岗位；中断后可恢复，重复写入会去重。
- 运行数据与模拟记录增加“评估失败”，与真正不匹配区分；模拟记录导出支持按此状态筛选。
- 更新图文使用指南，说明规则执行、可选模型输入、反馈和模拟开聊的完整流程。

## 修复

- 修复开聊、不合适和模拟记录的详情链接，统一在配置的招聘浏览器打开官方岗位页面，启动或打开失败时显示提示。
- 运行数据页面在任务运行期间每两分钟自动刷新，切换页面和任务结束时同步更新；空闲时不启用轮询。

- 开聊记录与不合适记录可从已有职位历史中补取薪资原文，保留日薪、月薪、年包或面议等实际表达；没有原始数据时仍显示未记录，不推算薪资。
- 详情复筛、模拟筛选与开聊前核验同步使用工作经验正则；前置规则未通过的岗位不调用 AI 评分。
- 提供 BOSS 活跃度作为模型输入时，发送实际采集的活跃状态。
- 输入勾选改变后，模型载荷跟随本次选择，不夹带上次资料；反馈停用时不使用反馈影响判断。
- 模型调用或格式失败不会伪装成有分数的不合适结论。

## 安装包

- `geekgeekrun-pro_0.20.1_arm64.dmg`：Apple 芯片 Mac。
- `geekgeekrun-pro_0.20.1_x64.dmg`：Intel Mac。
- `geekgeekrun-pro_0.20.1_x64_setup.exe`：Windows 10／11 x64。
- `geekgeekrun-pro_0.20.1_amd64.deb`：Debian／Ubuntu x64。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。

Mac 安装包采用临时签名、未经过 Apple 公证；Windows 安装包未使用商业代码签名。跨平台构建和安装包数据库检查不等同于全部设备上的完整 GUI 或 BOSS 在线测试。
